0. System Requirements

Before starting, verify your server has:

  • PHP 8.0+
  • MySQL 8.0+
  • Web Server: Apache or Nginx with mod_rewrite
  • Disk Space: 50 MB minimum
  • PHP Memory: 128 MB minimum
Required PHP Extensions:
mysqli (required), mbstring, json, fileinfo, gd (recommended)

1Download NovaStar51

  1. Download the star51.zip package
  2. Extract to your server web root
  3. Complete package, ready to use
Package structure 
star51/
├── nova/              ← Admin panel
├── file_db_max/       ← Large images
├── file_db_med/       ← Medium images
├── file_db_min/       ← Thumbnails
├── install/           ← Setup wizard (delete after install)
├── index.php          ← Frontend
└── ...

2Create Database

IMPORTANT: Database must be created before running the wizard.

Localhost (MAMP/XAMPP)

  1. Open phpMyAdmin (http://localhost/phpmyadmin)
  2. Click "New" in sidebar
  3. Database name: e.g. star51_db
  4. Collation: utf8mb4_unicode_ci
  5. Click "Create"

Shared Hosting (cPanel)

  1. Login to cPanel
  2. Go to "MySQL Databases" → "Create Database"
  3. Name: will be prefixed (e.g. user_star51)
  4. Write down full name, username and password
  5. Assign all privileges to user
Fields reference
Field Localhost Shared hosting
Database host localhost mysql.hosting.com
Database name star51_db user_star51
Username root user_dbuser
Password root or empty From cPanel

3Run Setup Wizard

  1. Open your browser
  2. Navigate to: http://your-domain.com/install/
  3. Fill in the installation form

Database Section

Enter the database credentials from Step 2. Use "Test Connection" button to verify.

Super Admin Section

  • First/Last Name: Your details
  • Email: Used for password recovery
  • Username: For login
  • Secure generated password: Recommended option, shown only once after installation
  • Custom password: Minimum 12 characters

Gmail SMTP (Optional)

With SMTP: Password recovery and outgoing contact confirmations

Without SMTP: Server mail delivery is used when available; verify it before relying on email recovery

Gmail app password setup
  1. Go to Google App Passwords
  2. Create a new App Password for "Mail"
  3. Copy the 16-character code
  4. Enter it in the "Gmail App Password" field
DO NOT use your regular Gmail password!

4Installation Complete

Success! If everything goes well, you'll see the success screen with login credentials.

Generated Files:

  • /nova/conf/nova_config_values.php
  • Database with 6 tables (ns_*)
  • Super Admin account (level 0)
  • .installed - Lock file
IMPORTANT - Security:
  1. Write down your credentials
  2. Delete /install/ folder for security:
    • Via Nova Admin → System Configuration → Installation File Removal
    • Or via FTP or terminal: rm -rf install/

5Login to Nova Admin

Login URL: http://your-domain.com/nova/

  1. Enter the username and the password selected or generated during installation.
  2. Click Login to access NovaStar51. Gmail SMTP does not change the login procedure.

Troubleshooting

  • Check MySQL is running
  • Check host (localhost or 127.0.0.1)
  • Verify port 3306 is open

  • Check username (case-sensitive)
  • Check password (case-sensitive)
  • Localhost: try root/root (MAMP)

  • Create database BEFORE wizard
  • Check exact name (case-sensitive on Linux)

  • Enable 2FA on Google Account
  • Use App Password (16 chars)
  • Email must be @gmail.com

Database Tables

Table Description
ns_admins Administrator accounts (4 levels)
ns_articles Universal collection system
ns_categories Main categories
ns_subcategories Subcategories
ns_requests Contact form
ns_login_security Rate limiting / Brute force protection

0. Requisiti di Sistema

Prima di iniziare, verifica che il tuo server abbia:

  • PHP 8.0+
  • MySQL 8.0+
  • Web Server: Apache o Nginx con mod_rewrite
  • Spazio disco: 50 MB minimo
  • Memoria PHP: 128 MB minimo
Estensioni PHP Richieste:
mysqli (obbligatoria), mbstring, json, fileinfo, gd (consigliata)

1Scarica NovaStar51

  1. Scarica il pacchetto star51.zip
  2. Estrai nella web root del tuo server
  3. Pacchetto completo, pronto all'uso
Struttura del pacchetto 
star51/
├── nova/              ← Admin panel
├── file_db_max/       ← Large images
├── file_db_med/       ← Medium images
├── file_db_min/       ← Thumbnails
├── install/           ← Setup wizard (delete after install)
├── index.php          ← Frontend
└── ...

2Crea il Database

IMPORTANTE: Il database deve essere creato prima di eseguire il wizard.

Localhost (MAMP/XAMPP)

  1. Apri phpMyAdmin (http://localhost/phpmyadmin)
  2. Clicca su "Nuovo" nella sidebar
  3. Nome database: es. star51_db
  4. Collation: utf8mb4_unicode_ci
  5. Clicca "Crea"

Shared Hosting (cPanel)

  1. Login a cPanel
  2. Vai a "Database MySQL" → "Crea Database"
  3. Nome: verrà prefissato (es. user_star51)
  4. Annota nome completo, username e password
  5. Assegna tutti i privilegi all'utente
Riferimento campi
Campo Localhost Hosting condiviso
Host database localhost mysql.hosting.com
Nome database star51_db user_star51
Username root user_dbuser
Password root o vuoto Da cPanel

3Esegui il Setup Wizard

  1. Apri il browser
  2. Vai a: http://tuo-dominio.com/install/
  3. Compila il form di installazione

Sezione Database

Inserisci i dati del database creato nello Step 2. Usa il pulsante "Testa Connessione" per verificare.

Sezione Super Admin

  • Nome/Cognome: I tuoi dati
  • Email: Usata per il recupero password
  • Username: Per il login
  • Password sicura generata: Opzione consigliata, mostrata una sola volta al termine
  • Password personale: Minimo 12 caratteri

Gmail SMTP (Facoltativo)

Con SMTP: Recupero password e conferme di contatto

Senza SMTP: Viene usato il servizio email del server, se disponibile: verificalo prima di affidarti al recupero password

Configurazione password per app Gmail
  1. Vai su Google App Passwords
  2. Crea una nuova App Password per "Mail"
  3. Copia il codice a 16 caratteri
  4. Inseriscilo nel campo "Gmail App Password"
NON usare la tua password Gmail normale!

4Installazione Completata

Successo! Se tutto va bene, vedrai la schermata di successo con le credenziali di login.

File Generati:

  • /nova/conf/nova_config_values.php
  • Database con 6 tabelle (ns_*)
  • Account Super Admin (level 0)
  • .installed - File lock
IMPORTANTE - Sicurezza:
  1. Annota le credenziali
  2. Elimina la cartella /install/ per sicurezza:
    • Via Nova Admin → Configurazione di Sistema → Rimozione file di installazione
    • Oppure via FTP o terminale: rm -rf install/

5Login a Nova Admin

URL Login: http://tuo-dominio.com/nova/

  1. Inserisci username e password scelta o generata durante l'installazione.
  2. Clicca Accedi per entrare in NovaStar51. Gmail SMTP non modifica la procedura di accesso.

Risoluzione Problemi

  • Verifica che MySQL sia avviato
  • Controlla host (localhost o 127.0.0.1)
  • Verifica porta 3306 aperta

  • Verifica username (case-sensitive)
  • Verifica password (case-sensitive)
  • Localhost: prova root/root (MAMP)

  • Crea database PRIMA del wizard
  • Verifica nome esatto (case-sensitive su Linux)

  • Attiva 2FA su Google Account
  • Usa App Password (16 caratteri)
  • Email deve essere @gmail.com
